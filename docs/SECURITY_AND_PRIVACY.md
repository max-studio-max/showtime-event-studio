# Security and privacy

## Today

- **No secrets in the repo.** The browser app uses none; the only secret is the optional Ticketmaster key, read by the gateway from `.env`. `.env*` is git-ignored and `.env.example` holds names only.
- **Local storage only.** The workspace lives in this browser's `localStorage`. Anyone with access to the browser profile can read it. Export/import is plain JSON.
- **No outbound actions.** SHOWTIME never posts, books, buys, emails or spends. "Request availability" opens the user's own email client with a draft; external links open in a new tab with `rel="noopener noreferrer"`.
- **Minimised guest data.** SERVICE stores cohort counts only — no names, dietary or accessibility details.
- **Audit log.** Every event edit and status change is recorded with actor, time and (for status) a required reason. Editing an approved event withdraws approval by default.
- **Untrusted HTML.** The only `dangerouslySetInnerHTML` is the plan SVG generated by `planSvg`, which escapes every user-entered label.

## Live-data gateway (v0.2)

- **Keys server-side only.** `TICKETMASTER_API_KEY` is read from `.env` by the gateway; the browser never sees it. `npm run build` runs `scripts/check-bundle.mjs`, which fails if any configured `*KEY*/*TOKEN*/*SECRET*` value or an `apikey=` literal appears in `dist/`.
- **No arbitrary fetches (SSRF).** Clients send parameters, never URLs. The gateway builds upstream URLs from fixed bases, requires https, checks a per-provider host allowlist, rejects credentials in URLs, refuses redirects, and caps response size and time.
- **Input validation.** Length, character and range checks on every parameter; supplier categories and OSM tags come from fixed lists.
- **Local only.** The gateway binds to 127.0.0.1, accepts GET only, and sets CORS only for the local app origin.
- **Redacted logs.** Keys and token-like query values are replaced with `[REDACTED]`; no personal data is logged.
- **Provider etiquette.** Identifying User-Agent without personal contact details, request spacing at or below each provider's policy, daily budgets, a circuit breaker to avoid hammering failing services.
- **External text is data.** Normalizers strip control characters and React renders everything as text; no provider HTML is executed.
- **Public business contacts** (phones/websites from OSM) are displayed for the user's own outreach only; SHOWTIME never sends messages or bulk-contacts anyone.

## Required before multi-user use (not built)

Server-side auth with MFA, tenant isolation and role enforcement; encrypted storage and backups; server-held OAuth credentials with scoped consent; signed uploads with file scanning; CSP and rate limiting; retention policies and consent for any personal data; data export and account deletion. See `ARCHITECTURE.md` → *Not built yet*.

Accessibility and safety outputs are advisory: SHOWTIME does not certify fire/egress, structural rigging, acoustics or code compliance.
